# Alien Blaster
### Overview
A 2D alien-shooting game built using Python and Pygame.  
Created to practice game development by building a game where players aim their crosshairs
at moving alien enemies and try to achieve a high score in 60 seconds.  
The game includes single-player and 2-player modes, 3 difficulty levels, customisable crosshairs,
and a leaderboard that saves scores using JSON.
