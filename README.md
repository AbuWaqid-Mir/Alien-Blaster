# Alien Blaster
### Overview
A 2D alien-shooting game built using Python and Pygame.  
Created to practise game development, event handling, collision detection and managing game states.  
Players control a crosshair to shoot moving alien enemies and aim to achieve the highest score within 60 seconds.  
The game included single-player and 2-player modes, with different difficulty levels and a leaderboard that saves scores using JSON.

### Features
- Main Menu
- Single-Player and 2-player mode
- 3 difficulty levels (Easy, Medium, Hard)
- Moving enemies that bounce off screen edges
- Crosshair controls (mouse/keyboard)
- Shooting and collision detection
- Score and miss tracking
- 60-second game timer
- Customisable crosshair colours
- Player name input and validation
- Game Over screen displaying final scores and misses
- Winner/draw detection (2-player mode)
- Leaderboard that saves top 5 scores for each game mode
- JSON file storage for leaderboard data
- Sound effects with ON/OFF setting
- Interactive buttons
- Background images for different screens

### Skills Demonstrated
- Pygame game development
- Functions
- Conditional statements and loops
- Event handling and keyboard input
- Mouse input and crosshair movement
- Collision detection
- Random number generation
- Game States management
- Score & Timer management
- Input validation
- Read and write JSON data
- Sort and store leaderboard scores
- Load and display images
- Play sound effects

### How To Run
Install Python.
Install Pygame by running the following command in the terminal: **pip install pygame
**
Clone or download the repository.
Open the project folder in PyCharm or another Python IDE.
Ensure the fonts, images and sounds folders are in the same project directory as main.py.
Run main.py.
